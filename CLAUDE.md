## Claude Code notes

- Before you commit, read `AGENTS.md` sections Branches, Commits, and Pull requests.
- Use `.github/pull_request_template.md` for the body of every pull request that you open.
- Do not add an emoji to a commit message or a pull request body, including in an attribution line.
- A pull request does not need a review from a teammate. You can approve and merge a pull request
  for the issue assignee that you work for.
